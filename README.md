# learning-languages

My workspace for learning English and Mandarin: study notes plus small practice apps.

## Notes
- [120-speaking-topics.md](120-speaking-topics.md): IELTS/TOEIC speaking topic rotation
- [chinese-self-study-plan.md](chinese-self-study-plan.md): Mandarin self-study plan

## Apps
| App | What it does |
|---|---|
| [apps/english](apps/english) | Daily English practice with a fullscreen focus mode. **Listening:** BBC 6 Minute English with a custom player, first-listen quiz, dictation and shadowing. **Speaking:** the 120-topic rotation with timed, recorded 3-round sessions, Whisper transcripts, fluency stats and an error log |

Each app is self-contained (its own `package.json`). Personal progress data and downloaded audio live in each app's `data/` folder and are not committed.

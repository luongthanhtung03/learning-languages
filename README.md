## Apps
| App | What it does |
|---|---|
| [apps/english-listening](apps/english-listening) | Practise listening with BBC 6 Minute English: custom player (±5s, speed, A–B loop), first-listen quiz, sentence dictation, shadowing |

Each app is self-contained (its own `package.json`). Personal progress data and downloaded audio live in each app's `data/` folder and are not committed.

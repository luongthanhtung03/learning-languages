# 120 Speaking Topics — 12-Block Rotation

Built for IELTS Speaking (target 7.0) and TOEIC Speaking. At 1–2 topics/day this runs **60–120 days**.

Topic types are mixed on purpose:
- **P2** = IELTS Part 2 style (personal, descriptive, past-heavy) — also the format that builds the 2-minute long turn
- **P3** = IELTS Part 3 style (abstract, opinion, requires justification)
- **TQ** = TOEIC Speaking Q11 style (opinion + 2 reasons, 60 seconds)

---

## Daily protocol

Do not just talk once. Three runs, ~6 minutes total:

| Run | Time | Focus |
|---|---|---|
| 1 | 90s (P2) / 60s (P3, TQ) | Content only. Don't stop. Prep ≤15s, no notes. |
| 2 | same | **Force the block's language target in** (see each block). |
| 3 | 60s (P2) / 45s (P3, TQ) | Compress. Speed, no fillers. |

Record all three. Only listen back to run 3.

**Non-negotiable rule:** never restart a sentence. If you get stuck, use a filler phrase (*"the thing is…", "what I mean is…", "something along those lines"*) and keep going. Restarting is the habit that costs you the fluency band.

---

## Weekly rhythm

- **Days 1–5:** new topics from the current block.
- **Day 6 — transcribe day.** Pick one recording. Write it out word for word. Mark errors yourself. This is where accuracy comes from; skipping it makes the whole thing pointless.
- **Day 7 — spaced revisit.** Re-do 2 topics from the *previous* block, once each, 60s. Immediate repetition builds speed; a one-week gap is what builds structural complexity.

Move to the next block when you've done all 10, regardless of how the last one felt.

## Self-check every 4 weeks

Re-record **Topic 11** (hometown) each month, same conditions, and compare against the previous version. Measure:
- Words per minute (transcribe 30 seconds, multiply by 2)
- Number of pauses over 2 seconds
- Number of false starts

If wpm is rising but errors aren't falling, you're getting faster at speaking badly — increase transcribe days from 1 to 2 per week.
